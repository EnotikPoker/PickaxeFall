# PickaxeFall

2D-игра для Android, вертикальный экран: **рулетка → физический спуск → добыча → продажа → постоянные улучшения**.

**Unity 6000.4.0f1 · Built-in Render Pipeline · UI Toolkit · Physics 2D**

PNG блоков и жирное начертание шрифта хранятся через **Git LFS**. До открытия нового клона в Unity:

```bash
git lfs install --local
git lfs pull
```

## Запуск

Открыть проект через Unity Hub, сцену `Assets/PickaxeFall/Scenes/Main.unity`, нажать Play. Для Game View выбрать 9:16, например 540×960. Нажать «Крутить рулетку», затем «В шахту».

Кирка появляется в небе и падает без ручного бокового управления. Она отскакивает от поверхности по нормали столкновения; в воздухе подталкивания нет. Пауза — кнопка с двумя полосками или **Escape**; при сворачивании приложение ставится на паузу.

Кнопка **Настройки** открывает громкость, выбор 30/60 FPS, уменьшение частиц и сообщения о добыче. Во время настройки активный спуск приостанавливается. Раздел «Шахта» — компактный экран над фоном, без прокрутки.

## Добыча и торговля

Все восемь материалов поступают в общий рюкзак. **Разрушение блока не начисляет монеты**: добычу нужно продать. Верхняя панель показывает кошелёк, результаты забега — потенциальную стоимость добытых ресурсов.

В рюкзаке можно продать весь запас, весь выбранный вид или введённое целое количество. Общая продажа требует подтверждения. Цель улучшения показывает, какие материалы стоит оставить. Вместимость не ограничена.

В магазине есть разделы «Кирки», «Добыча», «Удача». Урон и прочность улучшаются отдельно для каждого типа; редкие инструменты получают большую прибавку. Общие навыки дают дополнительную руду, шанс на отряд, отряд до пяти кирок, появление TNT после добычи руды, двойной верстак, усиленный взрыв, экономию прочности и однократное спасение последней кирки. Покупки требуют монет и блоков; первые уровни дешёвые, последующие дорожают. Карты и покупка новых типов кирок пока обозначены разделом «Скоро».

Правила, цены и формулы: [Docs/Economy.md](Docs/Economy.md).

## Кирки и шахта

| Кирка | Шанс | Базовый урон | Прочность |
|---|---:|---:|---:|
| Деревянная | 45% | 2 | 40 |
| Каменная | 30% | 4 | 72 |
| Золотая | 15% | 6 | 108 |
| Железная | 8% | 9 | 200 |
| Алмазная | 2% | 14 | 320 |

Результат рулетки выбирается один раз, независимо от анимации и генерации шахты. Каждый раунд получает новый seed: рельеф, пещеры, жилы, верстаки и TNT процедурные, не привязаны к маршруту кирки.

При удаче отряда одновременно падают 2–5 одинаковых кирок с независимой физикой. Камера старается вместить всех живых участников; прочность показана отдельно. Забег заканчивается после поломки последней кирки и проверки навыка спасения.

Верстак повышает тип ударившей его кирки и восстанавливает до 25% максимальной прочности, не более 28 за ступень. Это сохраняет ценность редкого выпадения и ограничивает бесконечные цепочки ремонтов. Бонусы исходного типа сохраняются до конца забега, бонусы нового типа не складываются с ними. Блоки остаются непрозрачными, повреждения отображаются восемью стадиями трещин; сломанные кирки рассыпаются.

TNT взрывается от удара и вызывает цепные реакции. Бонусный TNT возникает только на месте добытой киркой руды, сохраняя полученный ресурс. Взрывы сами не порождают бонусные TNT. Двойная мощность означает удвоение площади, то есть радиус ×√2. Взрывы не уничтожают верстаки. Ниже 40 м здоровье материалов растёт на 25% каждые 40 рядов: дальнейший спуск требует развития.

Физика, начальные характеристики и генерация настраиваются в `Assets/PickaxeFall/Data/DefaultBalance.asset`. Экономика и рецепты — в `Scripts/Data/Progression.cs`. Дробный урон хранится целыми полуединицами без округления прибавки 0,5.

## Сохранения

Ресурсы, монеты, рекорд и уровни улучшений сохраняются одним профилем `profile-v2.json` в `Application.persistentDataPath`. Запись атомарная, предыдущая версия остаётся в `.bak`. Старые PlayerPrefs импортируются один раз без обнуления. Повреждённые файлы не заменяются молча пустым профилем.

Покупки и продажи сохраняются до подтверждения операции; ошибка записи отменяет списание. Добыча сохраняется при окончании забега, сворачивании и каждые пять секунд активной игры. Незавершённый забег после закрытия не восстанавливается.

## Android

Для Unity **6000.4.0f1** установить Android Build Support, SDK & NDK Tools, OpenJDK и **CMake 3.22.1**. На этой машине модули установлены.

Меню **PickaxeFall → Build Android APK** создаёт `Builds/Android/PickaxeFall.apk`. Альтернатива: **File → Build Profiles → Android → Switch Platform → Build And Run**. В **Run Device** выбрать телефон. На телефоне включить отладку USB; на POCO/Xiaomi также разрешить установку через USB и подтвердить запрос установки.

Настройки: Portrait, ARM64, IL2CPP, минимальный API 26, пакет `com.enotikpoker.pickaxefall`. APK, ключи подписи и Unity-кэши исключены из Git.

## Проверки

**PickaxeFall → Validate game balance** проверяет рулетку, генерацию, 72 PNG, трещины, форму кирки, цены улучшений, транзакции, сохранения, ограничения навыков и кириллицу жирного шрифта.

**PickaxeFall → Build Linux smoke-test player** создаёт Development-плеер. Использовать отдельный каталог сохранений:

```bash
XDG_CONFIG_HOME=/tmp/pickaxefall-smoke-prefs ./Builds/Linux/PickaxeFall.x86_64 --smoke-test -screen-width 540 -screen-height 960 -logFile /tmp/pickaxefall-smoke.log
```

`--balance-probe -batchmode -nographics` измеряет 58 физических забегов: базовые, промежуточные и максимальные улучшения, включая пять кирок. CSV: `/tmp/pickaxefall-progression-balance.csv`.

Для отдельной проверки предельного алмазного отряда добавить `--legendary-balance --balance-seed=8127`. Результат записывается в CSV с seed в имени. Обычные забеги ограничены 600 игровыми секундами, предельные отряды — 1800; это предел проверки, а не ограничение игры. CSV обновляется после каждого завершённого забега.

`--economy-probe -batchmode -nographics` моделирует первый час: игрок по кругу развивает урон/прочность деревянной и каменной кирок и шанс отряда, оставляет нужные материалы и продаёт излишки. Время включает восемь секунд на меню и рулетку за забег. CSV: `/tmp/pickaxefall-economy-trace.csv`.

Development-сборки поддерживают изолированные предпросмотры `--preview-shop`, `--preview-luck`, `--preview-bag`, `--preview-sale`, `--preview-team`, `--preview-mine`, `--preview-settings`. На Android используется строковый extra `pickaxefall-test` со значением `smoke`, `shop`, `luck`, `bag`, `sale`, `team`, `mine` или `settings`. Эти режимы используют новый профиль и временные настройки в кэше и отсутствуют в обычном APK. **Build Android development verification APK** собирает проверочный APK отдельно.

Результаты проверок: [Docs/Verification.md](Docs/Verification.md). Устройство проекта: [Docs/Architecture.md](Docs/Architecture.md).

## Спрайты

В `Resources/Blocks` находятся 72 PNG из предоставленных архивов. Из `Blocks(1).rar` обновлены 24 спрайта: земля, поверхность, медь, железо, золото и алмаз. Обычные блоки и поверхность имеют размер 32×32, глубинные и специальные — 16×16. `.ase` не импортируются. Настройки: Sprite/Single, Point, без сжатия и mipmaps; Pixels Per Unit соответствует размеру изображения, поэтому один спрайт занимает один блок. PNG хранятся через LFS, `.meta` — обычным текстом. Соответствие архивам и SHA-256: [Docs/BlockSpriteSources.json](Docs/BlockSpriteSources.json).
