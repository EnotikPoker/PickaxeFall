# История версий

Нумерация `MAJOR.MINOR.PATCH`: исправления повышают PATCH, новые игровые механики — MINOR, большой пересмотр игры — MAJOR. До 1.0 игра находится в разработке; изменения баланса описываются в каждой версии. Сохранения мигрируют отдельно от номера игры.

Каждая выпущенная версия получает Git-тег `vX.Y.Z`. Для Android также увеличивается целочисленный `versionCode`, чтобы APK устанавливался поверх предыдущего с сохранением прогресса. Источник номеров — `Assets/PickaxeFall/Scripts/Data/GameVersion.cs`; команды сборки автоматически применяют их к Unity Player Settings.

## 0.2.0

- Обычный удар срабатывает по силе контакта без общего КД; вращение учитывается, лежание не добывает блоки.
- Свайпы в четырёх направлениях с пробитием первого материала и нажатие для пробоя нескольких материалов вниз.
- Общая энергия отряда, выбор управляемой кирки и семь новых ветвей улучшений приёмов.
- Верстаки полностью ремонтируют повышенную кирку; двойной верстак также заполняет энергию.
- Разные прибавки прочности для пяти типов кирок, усиление урона железной/алмазной и плавный рост здоровья глубинных блоков.
- Перебалансированы эффекты улучшений; результаты показывают их фактическую пользу. Магазин показывает число ударов сейчас и после повышения урона.
- Миграция профиля v2 → v3 с сохранением прогресса и резервной копией исходника.
- Номер версии виден в настройках игры; добавлены отчёты физических прогонов, экономики и проверки Android.

## 0.1.0

Состояние перед 0.2.0, коммит `3a48064`:

- Процедурная шахта, рулетка, пять типов кирок, физические отскоки, руда, TNT и верстаки.
- Рюкзак, продажа материалов, магазин постоянных улучшений и отряды до пяти кирок.
- Пользовательские текстуры блоков в Git LFS, пиксельный интерфейс и настройки игры.
- Сборка для Android, сохранение прогресса и автоматические проверки.
