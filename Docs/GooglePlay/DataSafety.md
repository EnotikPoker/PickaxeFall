# Data Safety — рабочий черновик

Контакты, подключение SDK и аккаунтов не завершены. Не переносить таблицу в анкету без сверки раскрытий **конкретных версий** SDK и реального трафика. Политика конфиденциальности описывает то же поведение, что и анкета.

| Источник | Данные/действие | Назначение и контроль |
| --- | --- | --- |
| Локальная игра | Монеты, добыча, улучшения, рекорды, спуск, настройки | Файлы на устройстве; очистка через настройки/удаление данных приложения |
| Возрастной экран | Только группа unknown/under18/adult и выбор персонализации | На устройстве; само число возраста не хранится нашим кодом и не отправляется |
| Play Games, по кнопке | Google player ID, профиль игры, облачный прогресс, достижения | Необязательные облако/достижения; спуск не загружается; удаление облака из настроек |
| Google Play Billing / Unity IAP | Подписанная квитанция, продукт, transaction/purchase token, результат платежа | Выполнение и восстановление постоянной покупки; локальный cache; платёжные реквизиты обрабатывает Google |
| Yandex Mobile Ads, только adult | IP/приблизительное местоположение по IP, технические данные устройства/приложения, реклама/взаимодействия, диагностика — сверить disclosure версии | Монетизация, предотвращение мошенничества; location consent=false, AD_ID/location permissions удалены; персонализация по отдельному выбору |
| AppMetrica 7.14.3, зависимость Yandex | Техническая статистика рекламного SDK; на POCO после взрослого согласия наблюдалась анонимная активация | Отключён app-ad analytics reporting, но это не отменяет всех рекламных метрик AppMetrica; учесть disclosure Яндекса |
| Kidoz, unknown/under18 | Контекстные рекламные запросы и технические данные по disclosure провайдера | Только детские форматы, без interest targeting и remarketing. Собственные сторонние mediation adapters не добавлены |

Нет нашего сервера/аналитики/чатов/пользовательского контента. Это **не** утверждение, что все SDK не передают данные. Unity Services Core является зависимостью IAP; проверить трафик пакета и его раскрытие отдельно, не отмечать отсутствие диагностики на основании отсутствия собственного аналитического кода.

В Play Console проверить определения collected/shared/ephemeral/required/optional для каждой категории. Даже неперсонализированная реклама может передавать технические сведения. Учесть IP-based approximate location, app interactions, diagnostics, identifiers и purchase history по фактическим SDK. Не обещать шифрование всех сетевых каналов без проверки. Удаление облачного слота не удаляет историю платежей Google или сведения у рекламных провайдеров; это явно объясняется на странице удаления.

Реальная публичная политика требует имени/контакта владельца, точного перечня SDK/целей, условий хранения/удаления, ссылок на провайдеров и даты. Возрастные/региональные юридические основания и согласия нужно сверить для стран распространения. В текущем шаблоне нет выдуманного разработчика или адреса.
