# PickaxeFall 0.8.3

Адаптация существующей игры для Яндекс Игр и перевод на английский. Версия Android — 13. Новые карты, навыки, загон и изменения базового баланса в этот выпуск не входят.

## Один проект, разные площадки

Общие физика, генерация, контент и экономика остаются в одном проекте. `IProfilePersistence`, `IGameTimeSource`, `IGameAdvertising` и `IPlatformLifecycle` отделяют игровые правила от сервисов площадки. `PlatformHost` подключает официальный SDK только в Web-player; Android продолжает использовать прежний `ProfileStore`. Нативная APK сохраняет `com.enotikpoker.pickaxefall`, ставится обновлением и работает без аккаунта Яндекса. Отдельная Dev APK сохраняет свой package ID и локальный ключ.

`PickaxeFall → Release` содержит команды сборки обычного Android, Dev и Yandex ZIP. Проверочный Web-архив собирается через `PickaxeFall → Verification → Build Yandex draft checks`. Его нельзя отправлять на публикацию: в нём есть диагностические команды и водяной знак Development Build. Публичный ZIP собирается без них.

## Языки и браузер

Каталог `Resources/Localization/en.json` содержит русский исходный ключ и английский перевод, включая обучение, названия материалов, навыки, требования, ошибки и рекламные сообщения. Исходные имена в сериализованном балансе не переводятся. Язык первого Web-запуска определяется SDK: `ru` — русский, остальные — английский. Ручной выбор хранится на устройстве. В Android исходным остаётся русский; переключатель доступен в настройках.

Вертикальное поле на ПК занимает высоту окна; боковые области оформлены фоном. На телефонах используется доступная высота окна, поддерживается изменение ориентации и запрос полноэкранного режима после касания. Мышь работает по умолчанию, свайп выполняется перетаскиванием. Спавнер на Android и сенсорном Web читает отдельные системные касания; мышь Web использует собственный обработчик без повторного подсчёта сенсорного ввода.

Потеря фокуса в Web, SDK pause/resume и реклама обрабатываются независимо от ручной паузы. Физика, энергия, жесты и время испытания останавливаются; закрытие рекламы не снимает другую причину остановки. Звук не запускается до первого действия пользователя, останавливается при скрытии страницы и рекламе. Game Ready отправляется после завершения заставки и первого прохода layout интерфейса.

## Сохранения

Профиль v8 и спуск v6 сохранены. Web использует версионированную оболочку с revision, базой облачной синхронизации, временем и рекламными квитанциями. Один атомарный `localStorage.setItem` фиксирует профиль и соответствующий ему спуск; неудачная запись не подтверждает покупку. После локального успеха профиль отправляется в облако очередью. При добыче изменения записываются по кадрам, снимок текущего спуска также обновляется периодически. На закрытие вкладки сохранение не откладывается.

Гость играет локально без регистрации. Вход в Яндекс предлагается только кнопкой с объяснением преимуществ. В облако переносятся монеты, ресурсы, прокачка, открытия, рекорды и квитанция бонуса; растущая шахта туда не входит. После загрузки облачного профиля на другом устройстве текущий спуск начинается заново. Переноса в Android/Google Play/App Store нет.

При разных версиях прогресса пользователь выбирает локальную или облачную; ресурсы не складываются. Обе копии сохраняются отдельно перед заменой. Ошибки сети повторяются с задержкой, ошибки квоты сохраняют старую запись. Сброс обновляет резервную копию, чтобы восстановление не возвращало удалённый прогресс. Облако проверяется перед записью и отправляется не чаще раза в 10 секунд; размер payload ограничен запасом ниже 200 КБ.

SDK не предоставляет compare-and-swap для `setData`: при строго одновременной игре конфликт может обнаружиться при следующей записи или входе. Локальные копии остаются на соответствующих устройствах. Очистка данных сайта удаляет локальный гостевой прогресс и спуск; облако доступно авторизованному игроку.

## Реклама

Все показы идут через SDK Яндекса. Внутренние таймеры определяют момент запроса; фактический показ зависит от платформы и наличия объявления.

- Между забегами: накапливаются 120 секунд активного спуска. Один запрос по кнопке «Ещё один забег». Только подтверждённый межзабеговый показ обнуляет этот счётчик; долг пропущенных роликов не накапливается.
- Длинный спуск: первый запрос после 300 активных секунд, следующие через 180 секунд после завершения предыдущей попытки. Предупреждение «2…1…» длится две секунды; игра заморожена уже во время предупреждения. Показ откладывается до завершения спавнера или активного приёма. Расписание сохраняется с локальным спуском.
- Счётчик после спуска независим от рекламы внутри спуска и от добровольного просмотра. Если близкий показ отклоняет SDK, переход сразу продолжается.
- Добровольный бонус: один просмотр даёт монеты в размере `floor(стоимость добычи забега / 2)`, ресурсы остаются. Цена фиксируется по правилам этого забега. Выдача — только по `onRewarded`, с сохранённой квитанцией и защитой от повторного callback. При ошибке локальной выдачи в текущем сеансе повторная попытка не требует нового просмотра.

**В публичном ZIP показ внутри спуска выключен.** Режим 5/3 включён в проверочном архиве для черновика. Документация связывает показы по таймеру с типичной длительностью уровня более пяти минут; применимость к бесконечной шахте с разной длиной попыток необходимо подтвердить у Яндекса. Публичный выпуск использует межзабеговую рекламу и добровольный бонус. Это условие не меняется автоматически по локальному таймеру.
