# Проверка прототипа

Проверено 28 октября 2026 года, **Unity 6000.4.0f1**, Linux Development player, графический запуск 540×960 с OpenGL Core.

## Результат

- C#-компиляция и Linux-сборка: успешно.
- Сохранённая сцена Main и ссылки на баланс, PanelSettings и USS: проверены.
- Настройки Android: Portrait, ARM64, IL2CPP, API 26, `com.enotikpoker.pickaxefall`.
- Все ресурсы в Assets имеют `.meta`; повторяющиеся GUID не обнаружены.
- 100 000 выпадений рулетки: распределение соответствует заданным весам с допуском 0,8 процентного пункта.
- Повторяемая генерация при одинаковом seed и ограничения глубин руды: пройдены.
- Баланс всех девяти блоков сериализован в `DefaultBalance.asset`; проверены порядок, здоровье, награды и суммарная вероятность руды.

## Игровая проверка

Автоматический сценарий в реально запущенном player прошёл **18 проверок**:

1. Старт в состоянии Ready.
2. Рулетка выбирает и экипирует кирку.
3. Кирка получает прочность.
4. Падение включает Rigidbody2D.
5. Физические столкновения разрушают блоки.
6. Кирка спускается ниже поверхности.
7. Удары расходуют прочность.
8. Блоки выдают монеты.
9. Пауза останавливает симуляцию.
10. Продолжение возвращает течение времени.
11. Верстак повышает класс кирки.
12. Верстак полностью восстанавливает прочность.
13. Реальные удары при тестовом запасе прочности завершают забег.
14. Кошелёк получает награду забега.
15. Повторный вызов завершения не дублирует награду.
16. Подгрузка до глубины 1500 сохраняет ограниченное число активных блоков.
17. Повторный забег сбрасывает глубину, добычу и число блоков.
18. Кошелёк сохраняется между забегами.

Маркеры успеха: `PICKAXEFALL_BALANCE_OK`, `PICKAXEFALL_BUILD_OK`, `PICKAXEFALL_SMOKE_OK`. Код выхода тестового player: **0**. Скриншоты четырёх этапов находятся в [Screenshots](Screenshots).

Проверка верстака включает вызов игрового обработчика и проверку характеристик; это не отдельная автоматическая проверка маршрута кирки к каждому верстаку. На скриншотах есть метка Development Build, поскольку они сняты в проверочной сборке.

## Что пока не проверялось

Android APK не собирался: Android Build Support, SDK, NDK и OpenJDK не установлены для текущего редактора. Работа на физическом телефоне, производительность мобильного GPU, жесты и безопасные области конкретных устройств требуют отдельного прогона после установки этих модулей.
