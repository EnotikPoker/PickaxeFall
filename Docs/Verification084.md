# Проверка 0.8.4

Unity 6000.4.0f1. Сборки выполнялись в `Builds/ValidationProject`. Сверены 112 файлов общего кода, данных, стилей и Web-адаптера; отпечаток `47ca3eacfcb79b6774249ad83a59fa0fe4025da9c516df987467b00042a09560`. Диагностические Runtime-файлы исключены из этого отпечатка и из публичных сборок. Локальные журналы и машинные доказательства — `Builds/Release084`.

## Выполнено

- Editor: 157 новых проверок Google Play (возраст, конфигурация публикации, достижения, изоляция аккаунтов/эпох, атомарная награда, конфликты, отказ записи, импортированные изображения). 2230 проверок платформенных данных/каталога. Проходят существующие проверки профиля, экономики, генерации, 97 506 проверок миров, 24 832 проверки оформления и 100 000 бросков рулетки. Баланс не менялся; новый длительный аудит баланса не запускался.
- Google Play на ПК: **355 проверок** настоящего игрового клиента и UI в отдельном Linux QA player с графикой 540×960. Возраст и отказ персонализации, видимая область и получение касаний поверх обучения, маршрутизация сетей, остановка реальной физики на рекламу и продолжение, однократный бонус и холодное чтение квитанции. Облако: выбор двух копий, сохранение заработанного во время запроса, долгий выбор, ошибка резервирования и выход офлайн, другой аккаунт, запоздалый callback, удаление облака, английский UI. Сеть заменена управляемыми callbacks. Файл: `runtime-google-last.log`.
- POCO: **357 проверок** отдельного `com.enotikpoker.pickaxefall.playqa`. Включают 11 проверок настоящего Unity IAP RSA-валидатора: корректная подпись, подмена, неверный продукт/пакет/токен, отменённый/отложенный платёж, проверенный офлайн cache и восстановление backup. Ключ и квитанции сгенерированы специально для QA; это не настоящий платёж Google. Последующие дополнительные сценарии облака повторены на ПК. Лог: `device-google-runtime-final3.log`.
- POCO: проверены настоящие возрастной экран, цифровой ввод и отдельный отказ персонализации. После взрослого выбора Yandex SDK показал **реальное demo-объявление**, затем игровое приложение снова было доступно. Наблюдалась анонимная активация AppMetrica после взрослого выбора; это учтено в черновике Data Safety. В scoped-логе QA нет managed exceptions. Обычная установленная игра не обновлялась и не удалялась; по окончании остановлен только Play QA.
- Обычный Linux player: **343 smoke-проверки**, **5956 проверок UI и перевода**. Отдельные процессы подтвердили запись → восстановление/продолжение/завершение → отсутствие возврата завершённого спуска. Файлы: `native-smoke-final.log`, `native-localization-final.log`, `native-{savewrite,saveread,savefinished}-passed.log`.
- Настоящий JavaScript-адаптер: **31 проверка**, включая независимые локальные и облачные пространства тестовой/публичной эпох. Сам выпуск остаётся в эпохе 0 и прогресс не сбрасывает.
- Chromium, настоящий Web player с локальным SDK-двойником: **17 игровых сценариев**, **8 сценариев облака**, **3 сценария сенсорного ввода** (10 одиночных нажатий, пять пар пальцев, удержание). Проверены конфликт при входе с настоящим нажатием на отдельное окно выбора, обе резервные копии, отказ сети, восстановление, отказ локальной продажи и повтор после восстановления хранилища. Файлы: `browser-full/{result,cloud-result,touch-result}.json`.
- Публичный Web ZIP: готовность, отсутствие QA bridge, отключённая mid-run реклама, гостевое сохранение, перезагрузка, отсутствие необработанных JS-исключений. Файл: `public-web/result.json`.
- AAB и Play APK: версия 0.8.4/code 14, API 36, ARM64, Billing 8.3.0, отсутствие AD_ID/location и автозапуска рекламных/Play Games providers; системный облачный backup выключен. Проверены подпись, bundletool validation, 16 КБ для всех ELF LOAD segments, APK ZIP alignment и отсутствие Dev/QA. Файлы: `aab-release-check.json`, `play-apk-release-check.json`, `aab-signature.log`.
- Обычная APK: та же подпись, что у 0.8.3; нет Play Games, Billing, Kidoz или Yandex Mobile Ads в manifest. Play APK соответствует новому app-ключу, upload-ключ отдельный. Сертификаты — `signing-certificates.json` (публичные отпечатки, не приватные ключи).
- Web ZIP: около 24 МБ, index.html в корне, переносимые пути, нет Dev/QA/посторонних рекламных сетей; публичная реклама внутри спуска отключена. Файл: `web-release-check.json`.
- Production preflight намеренно отклоняет пустую конфигурацию: контакты, URL, ID сервисов, лицензионный ключ и неподтверждённые детские форматы. Генератор privacy/deletion без контактов выпускает только явно помеченный черновик и отказывает при попытке подготовки публичной страницы.
- Изменённые PNG проверены как Git LFS pointers. Сканирование staged-файлов не обнаружило исходный код разработчика, его salt/hash, пароли подписи, закрытые ключи или QA receipt asset. Исходные пользовательские настройки импорта/иконки сохранены; обратная проверка `preexisting.patch` проходит.

## Повторение

UI-проверкам player нужна графика и вертикальное разрешение. `-nographics` подходит для Editor-сборки, но не подтверждает видимые bounds интерфейса.

```bash
python3 Tools/SyncValidationProject.py
# В изолированном Unity: executeMethod PickaxeFall.Editor.DesktopVerificationBuild.PlayQa
Builds/ValidationProject/Builds/PlayQA/PickaxeFall.x86_64 -batchmode -screen-width 540 -screen-height 960 -screen-fullscreen 0 --google-check -logFile /tmp/pickaxefall-google-check.log
node Tools/TestYandexBridge.cjs
python3 Tools/RunWebChecks.py Builds/ValidationProject/Builds/Yandex/PickaxeFall-0.8.4-Draft --output Builds/Release084/browser-repeat --suite full
```

Для трёх процессов холодного восстановления нужен один **новый GUID в формате N, 32 hex-символа без дефисов**, параметр `--resume-check-id=...`; последовательно `--savewrite-check`, `--saveread-check`, `--savefinished-check`. Неверный ID намеренно отклоняется. Промежуточные неудачные запуски сохранены в отдельных логах и не включены в успешные результаты.

## Не подтверждено и требуется до публикации

Реальные Google Play checkout/license tester, отложенная семейная покупка, серверный возврат и восстановление на другом устройстве; настоящий Play Games login/cloud/12 достижений; реальные monetization IDs Яндекса; Kidoz publisher, выплаты в Беларусь, сертификация конкретной версии и закрытие детских форматов за пять секунд. SDK-двойники и самоподписанные QA-квитанции этих проверок не заменяют.

Нет публично размещённых privacy/deletion/app-ads.txt, выбранных имени/почты разработчика, окончательных материалов карточки и отправки в Play Console. Публикация и модерация не выполнялись. Инструкция и список ручных сценариев — [GooglePlayPublishing.md](GooglePlayPublishing.md). Не подтверждается автоматическое прохождение модерации. Для 1.0 отдельно переключаются эпоха сохранений и достижения; прямую релизную APK нужно выпускать с app-подписью вместо старого тестового debug-ключа.
